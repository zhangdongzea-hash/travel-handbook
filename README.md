# 行旅 · 私人旅行手册程序 v1.2

此公开目录只含通用程序、公开景点照片目录、署名和许可证，不含个人行程、交通订单、酒店或票券二维码。
真实数据只从设备授权的私有仓库读取。不要上传private/、体验HTML、发布向导或整个完整包。

## 照片

photo-manifest.json记录真实照片的原始来源、作者、年份、许可与裁切说明。照片不代表实时景象。
photos/由本机发布向导按许可下载、缩小、压缩后写入。CC BY-SA图片的这些改编版本保留原许可证。
本次交付本身未下载照片字节，未本地化时通过原来源联网加载。加载失败时有明确状态，不用随机照片替代。
程序不请求地图API密钥，不发送GitHub令牌给图片网站。所有外链无referrer。
